@fluency-education/scc

Standard Celeration Charts as SVG, with zoom and hover cards in the browser.

1. Render an empty chart

renderChart returns the chart as an SVG string. Every option is optional, so with none it draws a blank chart: the full grid of 140 days, ready to print or to fill in later. 

import { renderChart } from "@fluency-education/scc";

document.querySelector("#empty").innerHTML = renderChart();

2. Plot some data

Pass counts and timings, one per day, to plot them. renderChart touches no DOM, so it runs on a server as well as in the browser. The SVG fills the width of whatever it is put in. 

import { renderChart } from "@fluency-education/scc";

document.querySelector("#basic").innerHTML = renderChart({
  // One entry per day from day 0. -1 marks a day with nothing recorded.
  timingSeconds: [60, 60, 60, -1, 60, 60, 60],
  corrects:      [12, 15, 14, -1, 18, 20, 22],
  errors:        [ 4,  3,  3, -1,  1,  2,  0],
});

3. Add dates, phases, zoom and hover cards

A startDate labels the axis with dates. Each phase can set an aim (drawn as a star) and a weekly celeration (drawn as a learning line). Once the SVG is in the page, enableZoom turns on the zoom buttons and drag-to-pan, and enableHover shows a card over each mark and line. Try both on the chart below. 

import { enableHover, enableZoom, renderChart } from "@fluency-education/scc";

const container = document.querySelector("#full");
container.innerHTML = renderChart({
  startDate: "2026-09-07",
  timingSeconds, corrects, errors,
  phases: [
    { name: "Baseline", endDay: 6 },
    { name: "Practice", endDay: 34, aim: 20, celeration: 1.25 },
    { name: "Two minute timings", aim: 40, celeration: 1.25 },
  ],
});
const chart = container.querySelector("svg");
enableZoom(chart);
enableHover(chart);

4. Re-render when the data changes

enableZoom and enableHover each return a function that removes their listeners. Call them before replacing a chart, such as when a learner's data changes or a component unmounts. Edit the fields below to see it in action. 

let disable = () => {};

function update(options) {
  disable();
  container.innerHTML = renderChart(options);
  const chart = container.querySelector("svg");
  const disableZoom = enableZoom(chart);
  const disableHover = enableHover(chart);
  disable = () => { disableZoom(); disableHover(); };
}

Rendering on a server

Because renderChart returns a string, a server can send the chart in its HTML so it shows before any script loads. The page then only needs to call enableZoom and enableHover on the SVG it already has. 

// On the server
import { renderChart } from "@fluency-education/scc";
const page = `<div id="chart">${renderChart(options)}</div>`;

// In the browser
import { enableHover, enableZoom } from "@fluency-education/scc";
const chart = document.querySelector("#chart svg");
enableZoom(chart);
enableHover(chart);
